Add `Icon`: renders any SVG icon (Lucide, Heroicons, your own) at a type-scale size with one stroke weight from the new `--icon-stroke` token. Decorative by default, `label` makes it an image. `.icon` semantic classes for plain HTML. `Button size="icon"` now warns in development when it has no accessible name.
